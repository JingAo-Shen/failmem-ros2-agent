## 2. 具体机制差异深度剖析

1. **ExpeL (经验与知识提取)**：
   - ExpeL 假设从交互历史（包括失败任务）中可以让 LLM 自发归纳出跨任务可迁移的高层规则（Rules）。
   - **本研究差异**：ExpeL 没有区分“规则中包含的知识”究竟是与任务因果直接相关的经验，还是仅仅因为示范了合法的工具调用语法或环境名词。本研究通过 Condition C（通用工具说明）与 Condition E（任务描述）精确解耦这部分收益。

2. **LearnAct (基于试错的动作学习)**：
   - LearnAct 将任务失败归因于预设动作空间（Action Space）不足，通过 LLM 编写和修订 Python 动作函数来扩展可执行技能。
   - **本研究差异**：LearnAct 依赖修改代码工具实现闭环，而本研究在固定动作空间与标准 API 环境（ScienceWorld）下，探究纯上下文失败轨迹是否直接包含可迁移的交互启发。

3. **Sentry (失败触发检索与恢复验证)**：
   - Sentry 明确指出其经验条目仅包含“验证过的成功恢复经验”（*“Sentry adds only verified recovery lessons; unresolved episodes produce none”*）。
   - **本研究差异**：Sentry 本质上学习的是“错误状态下的成功补救程序”，回避了未经成功续写的纯失败轨迹。本研究直接研究：一条未能完成任务的自然失败轨迹，其交互片段本身是否具有超出通用文档的迁移价值。

4. **SkillPivot (有效前缀、错误后缀与局部更新)**：
   - SkillPivot 将轨迹切分为有效前缀与错误后缀，其核心是在枢纽点（Pivot Point）进行重新分支采样，以对比正负决策差异。
   - **本研究差异**：SkillPivot 依赖昂贵的分支重采样来消除错误后缀。本研究关注单次前向执行产生的自然失败轨迹，在不进行多重续写搜索的前提下，评估其信息收益的真实边界。

## 3. 本轮判别实验的学术定位

本轮实验**不声称超越上述任何已有工作**，也不构建复杂的新记忆更新架构，而是作为一项**机理判别实证研究**，精确回答：
> **“自然失败轨迹所带来的任务收益，究竟源于动作语法与接口示范（H1）、任务描述线索（H2）、上下文长度与一般示范效应（H3），还是真正来源于跨任务相关的交互知识（H4）？”**
