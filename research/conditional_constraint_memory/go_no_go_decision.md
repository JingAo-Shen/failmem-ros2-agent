# 新方向立项立论与 Go/No-Go 决策报告 (One-Page Decision)

> **决策基准**：本报告综合 Stages 1–11 历史证据总账、相关文献核验（含 ACL 2024 Agent-Pro、Safe RL Shielding、Constrained Tool Decoding）、全套 53 项 CPU 单元与生产集成测试，以及冻结协议下的 Pilot V2 (36 运行) 与 Pilot V3 诊断实验 (12 运行)。预算用完即停止，不扩大实验。

## 一、核心决策三问明确回答

### 1. 相比动态事实记忆 (B2)，候选方法 (Method M) 究竟多做了什么？
- **动态事实记忆 (B2)**：记录环境客观状态命题（World Facts）。B2 将观测到的事实直接放入 Prompt 上下文，依赖大模型自身的自回归推理去自发规避冲突。
- **候选条件化失败约束记忆 (M)**：在 B2 基础上显式增加了独立的确定性生命周期状态机：
  1. **规则有效性 (Validity)** 与 **当前适用性 (Applicability)** 解耦；
  2. **候选试探机制 (CANDIDATE Probationary Trial)**：单次提取的规则默认处于候选期，允许有限试探执行，不直接硬阻断；仅在复现后升级为 `SUPPORTED`；
  3. **通用谓词门禁与主动探测 (Generic Predicate Gating & Probing)**：在动作提议后、实际执行前评估前置条件，当条件为 `UNKNOWN` 时触发针对性探测；当动作在适用条件下成功执行时将规则标记为 `CONTRADICTED`。

### 2. 这个差异为何可能带来可测收益？
1. **防止模型概率采样带来的重复盲目尝试**：通过执行前门禁确定性拦截已知必败动作；
2. **避免过时反思的守旧死锁**：当条件解除变为 `NOT_APPLICABLE` 时释放动作，避免传统纯文本反思的不可逆负向偏置；
3. **防止候选假设过度阻断**：候选规则放行机制保护可行动作不被初次单点偶发报错扼杀。

### 3. 区分有效机制与重新包装的关键评估边界
为避免在探索偏置下脱离因果检验而武断下结论，需在严格控制变量与真实因果介入下评估：
1. **在冲突前提实际发生时是否具备确定性防护**：当 Agent 提议被前置条件禁用的动作时，门禁能否有效实施精准拦截（TP 拦截）并防止重复失败，而非依赖模型自回归的不可靠猜测；
2. **在动态条件解除时是否避免死锁**：当约束条件变化解除时，机制能否及时恢复放行，而非造成永久性负向偏置或高误阻断（FP 误拦截）；
3. **成本与收益权衡**：状态维护、主动探测及生命周期转化的开销与减少的执行故障风险相比是否在合理工程边界内。

## 三、诊断实验四问明确解答与因果归因

### Question A: 修复 B2-G 后，B2-G 与 M 的成功率差距是否消失？
**回答**：**完全消失**。在补齐 B2-G 的规则结构接入与挂起动作执行后，B2-G 与 M 均实现 **3/3 (100%)** 成功率。V3 Smoke 阶段出现的 B2-G (0/2) 纯属未挂载规则管理器与动作执行截断的工程漏洞，并非通用门禁原理性缺陷。

### Question B: M 的收益究竟来自“执行前主动探测”还是“规则生命周期”？
**回答**：**当前收益主要由通用主动探测解释，而非规则生命周期**。
- 在 `inst5_stale_observation` 中，M 在提议 `start_service:port=18080` 时因观测过期触发 1 次 `PROBE` 主动探测刷新了状态；
- 但由于规则处于 `CANDIDATE` 状态，M 执行了候选试探机制放行了该动作，导致实际产生 1 次 OS 失败（Errno 98）；
- 反观 B2-G，依靠记忆中的规则约束直接自适应选用 18081 端口，以 **7 步、0 执行错误** 高效完成任务。

### Question C: 细粒度审计指标总账
- **规则匹配次数 (Rule Matches)**: 50
- **ALLOW 放行次数**: 48
- **PROBE 主动探测次数**: 1
- **BLOCK 阻断 (TP / FP)**: 0 / 0
- **Candidate 候选试探次数**: 1
- **DEFERRED_UNKNOWN 延期次数**: 0
- **观测/结果更新事件数**: 48
- **真实 Validity 状态变化数**: 1 (inst5 中 CANDIDATE $\to$ SUPPORTED)

### Question D: 当前任务集下，是否存在生命周期优于通用门禁的直接经验证据？
**回答**：**不存在直接经验证据表明生命周期机制优于公平配置的通用门禁**。在同等规则知识与执行闭环下，通用谓词门禁 B2-G 在成功率（100% vs 100%）、错误避免（0 错误 vs 1 错误）和平均步数（7.67 vs 8.67）上甚至略优于 M。当前收益主要由通用主动探测解释；生命周期的独立增益在当前任务集下仍未得到检验。

## 四、最终 Go/No-Go 结项决策决议

### 决策结论：【生产执行路径全线贯通；核心收益源于主动探测；生命周期独立增益未获验证】

1. **第一层：CPU 单元与集成测试套件全量闭环（53/53 Pass，100%）**
   - 包含 Paths A/B/C、Loops A-I 以及 7 项严密回归测试（对称性、挂起执行保全、`probe_file` 细粒度权限区分、状态机因果转移等），逻辑闭环完备。
2. **第二层：生产执行路径与实验隔离全部到位**
   - 源记忆快照 SHA256 冻结、各组深拷贝独立执行、顺序不变性验证、真实 OS 失败无人工篡改。
3. **第三层：大模型真实评测结论（科研诚信据实定论）**
   - 12 个诊断 episode 实测证实：一旦公平配置，B2-G 与 M 表现完全对称；
   - 当前在探索型智能体任务中，**“执行前主动探测”已足以提供核心保护**；复杂的规则生命周期管理（候选期试探、支持计数跃迁）并未带来可测的独立增益。
4. **结项建议**：
   - **严格遵守计算预算**：立即冻结并结束计算，不开展 32 目标大矩阵评测；
   - **研究结论如实上报**：明确记录“主动探测具有直接工程保护价值，规则生命周期在当前短流程多步运维任务中未观察到统计独立收益”，作为阶段性结项依据。
