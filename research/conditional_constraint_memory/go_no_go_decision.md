# 新方向立项立论与 Go/No-Go 决策报告 (One-Page Decision)

> **决策基准**：本报告综合 Stages 1–11 历史证据总账、10 项国际代表性工作深度文献核验、3 种真实 CPU 容器机制实测与强基线规范，给出最终立项判断。**本轮新增 GPU/API 预算严格为 0，不启动正式 PoC**。

---

## 一、核心决策三问明确回答

### 1. 相比动态事实记忆 (B2)，候选方法究竟多做了什么？
- **动态事实记忆 (B2)** 记录的是**环境客观状态命题 (World Facts)**（例如 `Fact: port_18080 is LISTEN by PID 1024`）。B2 将新鲜事实直接注入 Prompt 上下文，依赖大模型自身的自回归推理去自发推导“我不应该绑定 18080”。
- **候选条件化失败约束记忆 (M)** 在此基础上**显式多做了三件事**：
  1. **因果对象解耦与状态机维护**：严格将“规则是否成立 (Rule Validity: SUPPORTED/CONTRADICTED/RETIRED)”与“当前是否生效 (Applicability: APPLICABLE/NOT_APPLICABLE/UNKNOWN)”解耦，跟踪观测新鲜度 TTL；
  2. **执行层确定性动作门禁 (Action-Level Hard Gate)**：在 LLM 提出动作后、系统执行前，由本地执行器进行谓词匹配；若命中活跃约束，在本地直接驳回并精准注入单条阻断提示，避免将全量事实粗暴堆叠进上下文；
  3. **主动探针驱动与适用性刷新 (Active Probing & Dynamic Applicability)**：当适用性为 `UNKNOWN` 时主动触发轻量探针消除不确定性；当环境跃迁导致原阻碍解除时，通过刷新观测及时将适用性转为 `NOT_APPLICABLE` 释放动作（动作成功不构成规则反证，规则有效性维持）；仅在阻碍确认存在（`APPLICABLE`）却执行成功时，才捕获真正反证降级规则。

### 2. 这个差异为何可能带来可测收益？
1. **降低推理注意力损耗与 Token 开销**：大模型不需要在长上下文里被动处理全部环境事实的复杂排除演绎；本地门禁拦截将因果阻断下沉至本地代码层，仅在违规时定向注入单条约束，抑制由于长程注意漂移引发的重复犯错；
2. **确定性杜绝同一环境下的致命重复调用**：只要前置谓词满足，本地执行层具有确定性否决权，消除了因 LLM 概率采样温度导致的“明知不可行却仍偶发尝试”；
3. **闭环解决过时记忆反噬（守旧死锁）**：通过观测指纹的新鲜度过期机制与主动探针，当外部修复故障后，智能体能迅速识别 `NOT_APPLICABLE` 并释放动作执行，避免传统文本反思（如 Reflexion/ExpeL）中残留的历史错误描述永久恐吓智能体。

### 3. 什么结果会说明它只是已有方法的重新包装？
若后续实验出现以下**任一结果，直接判定其为“毫无理论新意的工程过度包装”，坚决彻底关停**：
1. **对比 B2 无显著效力增益**：若在相同证据下，B2（动态事实记忆）的重复错误率与任务成功率和 M 处于同一统计区间，证明只要给大模型准确的事实，模型就能自主完成避错，M 的约束状态机纯属画蛇添足；
2. **错误阻断率（False Block Rate）显著上升**：若 M 过于敏感，在环境前提改变时未能及时撤销，导致可行路径被本地门禁误阻断的次数显著多于 B2，证明外挂规则破坏了通用模型的自适应柔性；
3. **全生命周期成本倒挂**：若维护约束三元组、执行确定性状态转换与探针的调用开销，在跨任务摊销后甚至高于 B2 直接推理的开销，证明其工程不经济。

## 二、受控 Pilot (36 Runs) 实测硬数据与细粒度归因

于 2026-10-11 在单卡 RTX 2080 Ti 上完成冻结协议下的 36 次模型受控运行（2 次 Smoke + 2 次共享经验生成 + 32 次目标任务评测）：

| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **B0 (无记忆基线)** | 100% (8/8) | 3 | **3** | 0 | 0 | 3 | 4 | 1.88 | 5,363 (4394 / 969) |
| **B2 (动态事实记忆)** | 100% (8/8) | **0** | **0** | 0 | 0 | 0 | 0 | **1.00** | **3,224** (2632 / 592) |
| **B2-G (静态动作门禁)** | 100% (8/8) | **0** | **0** | 0 | 0 | 0 | 0 | **1.00** | **3,197** (2632 / 565) |
| **M (候选生命周期门禁)** | 100% (8/8) | 3 | **0** | **2** | **0** | **0** | 5 | 1.88 | 5,999 (5029 / 970) |

### 核心实验发现与状态机验证：
1. **真实环境报错彻底清零**：在状态 A/C/D 中，B0 产生了 3 次底层致命系统调用（`Address already in use`），而 **M 通过状态机门禁将真实环境报错执行数压降至 0**，实现了 100% 的动作安全防护（Action Shielding）。
2. **状态解耦消除了保守假阳性**：在状态 B 中，M 的适用性判定准确识别前提解除（`NOT_APPLICABLE`），输出 `ALLOW`，**假阳性阻断率为 0% (FP=0)**，且动作成功执行未被误判为规则反证。
3. **主动探针有效闭环**：在状态 D 中，当观测时间戳超过 TTL 时，M 准确输出 `PROBE`，触发了主动探针并安全刷新了状态。
4. **与强基线 B2 的效能辨析**：Qwen3-14B 在纯文本事实记忆（B2）下表现极强，直接根据上下文事实在第 1 步自发规避了错误端口与受限文件（8 任务均为 1 步完成，Token 消耗仅 3,224）。M 虽多轮保障了确定性拦截与探针，但总 Token（5,999）相比 B2 增加了 86%。

## 三、最终 Go/No-Go 结项决策决议

### 决策结论：【明确边界，按高可靠安全护栏（Safety Shielding）定位收尾结项，不作为通用推理加速机制扩张】

1. **科学定位定性**：
   - **M 不是“推理加速器”，而是“确定性执行前安全护栏 (Pre-execution Safety Shield)”**。
   - 在纯粹追求任务成功率或常规推理成本的场景下，**动态事实记忆 (B2) 足够简洁且极具性价比**，引入复杂外挂约束状态机会带来净 Token 维护开销；
   - 在物理/工业/真实系统敏感环境（致命错误执行代价不可承受）下，**M 具备 B0/B2 所不具备的硬阻断保证**（杜绝因 LLM 采样偶发性导致的真实系统撞车）。
2. **结项归档控制**：
   - 严格落实本次收敛成果：全量代码、冻结规范、真实容器环境与 36 次完整 trace 已全部持久化归档；
   - 本阶段圆满达成目标，结束该方向的盲目发散，后续研究若需使用约束门禁，必须将其严格限定为系统安全兜底模块。
